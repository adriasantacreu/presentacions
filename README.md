# Presentacions interactives

Presentacions de classe en HTML amb l'estètica del tema `adria` (Beamer): resultats que es revelen amb ▶, ginys per experimentar, generador d'exercicis amb comprovació i mode lectura. Un sol fitxer autònom per presentació: funciona sense internet, al mòbil i al navegador de la pissarra digital.

Web: https://adriasantacreu.github.io/presentacions/

Aquest repositori només conté les presentacions publicades (la versió per a l'alumnat, sense les diapos de solucions de les pauses). Es generen a partir de fonts en Markdown amb un generador privat; no s'editen a mà.

| Fitxer | Què és |
|---|---|
| `index.html` | Portada, generada a partir de `cataleg.json` |
| `<curs>/<tema>.html` | Cada presentació |
